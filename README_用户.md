# LegalMask · 律师文书智能脱敏工具

**一句话介绍**：本地运行的法律文书脱敏工具，一键隐藏当事人信息再还原，全程不联网。

---

## 运行方式

双击 `LegalMask` 图标，浏览器会自动弹出操作界面（地址：`http://localhost:8501`）。

> 首次启动约需 5–10 秒，请耐心等待。

---

## 三步使用

| 步骤 | 操作 |
|------|------|
| 1. 脱敏 | 上传 Word 或 PDF 文件，点击「开始脱敏」，下载脱敏版文件 |
| 2. AI 分析 | 将脱敏版文件提交给 AI（ChatGPT / 文心等），获取分析建议 |
| 3. 还原 | 将 AI 返回的文本粘贴到「还原」区，一键替换回真实当事人信息 |

---

## 隐私承诺

- **完全本地运行**，不依赖任何外部服务器
- **零网络连接**，文件和当事人信息始终留在您的电脑上
- 程序关闭后，所有临时数据自动清除

---

## 支持格式

- Word 文档（`.docx`）
- PDF（含文字层的可检索 PDF）

**暂不支持**：扫描版 PDF（图片型 PDF 需先 OCR 转换）
