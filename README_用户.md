# LegalMask · 律师文书智能脱敏工具

**一句话介绍**：本地运行的法律文书脱敏工具，一键隐藏当事人信息再还原，全程不联网。

---

## 运行方式

双击 `LegalMask` 图标，浏览器会自动弹出操作界面（地址：`http://localhost:8501`）。

> 首次启动约需 5–10 秒，请耐心等待。

---

## 三步使用

| 步骤 | 操作 |
|------|------|
| 1. 脱敏 | 上传 Word 或 PDF 文件；如有自动识别遗漏，可在「手动补充敏感字段」中每行填写一个词条，再点击「开始脱敏」并下载文件 |
| 2. AI 分析 | 将脱敏版文件提交给 AI（ChatGPT / 文心等），获取分析建议 |
| 3. 还原 | 将 AI 返回的文本粘贴到「还原」区，一键替换回真实当事人信息 |

---

## 隐私承诺

- **完全本地运行**，不依赖任何外部服务器
- **零网络连接**，文件和当事人信息始终留在您的电脑上
- 程序关闭后，所有临时数据自动清除

---

## 支持格式

- Word 文档（`.docx`）
- PDF（文字版或扫描版）

扫描版 PDF 会使用本机 OCR 自动识别，文件不会上传到网络。PDF 脱敏后会保留原版式，页面以高分辨率图像保存，并附可检索文字层。嵌入式 Logo、印章和签名图会被白底遮盖。文件体积通常会大于原 PDF。

OCR 对模糊、倾斜、手写或低分辨率扫描件可能存在识别误差，请处理后人工核查。

自动识别后仍有遗漏时，可在「手动补充敏感字段」中填写项目代号、内部编号或其他特定词条。系统按原文精确匹配，并与其他敏感信息一样写入 Mapping，支持后续还原。
