03 / GET STARTED

下载后，
双击就能用。

不需要安装 Python，也不需要打开命令行。选择你的系统下载，文件和 OCR 始终只在本机处理。

Windows 安装版 ↓ macOS 版本
WINDOWS 10 / 11 · 64 位 Windows 安装版 下载后双击安装，从桌面或开始菜单启动 ↓ APPLE 芯片 Apple Silicon 适用于 M1 / M2 / M3 / M4 ↓ INTEL 芯片 Intel Mac 支持 macOS 12 及以上 ↓

Mac 用户：解压后把 LegalMask 拖进“应用程序”。首次打开请按住 Control 点按图标，再选择“打开”；如果系统没有显示“打开”选项，请前往“系统设置 → 隐私与安全性”点击“仍要打开”。

不确定芯片类型？点击左上角苹果菜单 →“关于本机”查看“芯片”或“处理器”。

Windows 免安装便携版 浏览源码

IMPORTANT NOTE

仍需人工复核。

OCR 对模糊、倾斜、手写或低分辨率扫描件可能存在识别误差。提交 AI 前，请检查脱敏结果并确认没有遗漏实体。程序被强制终止时，退出清理无法保证执行。
